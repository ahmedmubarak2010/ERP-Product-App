# ERP Product App

A modern ERP Product Management application built with HTML, CSS, and JavaScript.

## Features

- Add Products
- Update Products
- Delete Products
- Search Products
- Filter by Category
- Sort Products
- Local Storage Support
- Inventory Statistics
- Responsive Design

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage

## Getting Started

1. Clone the repository.
2. Open index.html in your browser.
